📝 Notes Guide

Everything you can do with the Notes feature in Vibe Tasks

1. Editor Basics

The TipTap WYSIWYG editor supports rich text formatting:

  • B Bold · I Italic · ❄ Strikethrough
  • H1 H2 H3 — Section headings
  • • Bullet list · 1. Numbered list
  • <> Code block

2. ☑ Checklists New

Create interactive task lists inside any note:

  1. Click the ☑ button in the toolbar — a checkbox list is inserted
  2. Type your task text and press Enter for the next item
  3. Click the checkbox to toggle done / undone
  4. Use Tab to indent (nested subtasks) or press Enter on an empty item to exit the list

3. 🔗 Note Linking (WikiLinks) New

Link between notes by typing [[ followed by the note title:

  1. Type [[ anywhere in the editor — an autocomplete dropdown appears
  2. Continue typing to filter notes by title
  3. Use ↑ ↓ to select a result, then Enter to insert
  4. The link renders as clickable text — click it to jump to that note

Links survive HTML round-trips through the database. You can also paste [[Note Title]] manually.

4. 🔍 Quick Switcher New

Jump to any note instantly without touching the mouse:

  • Press Ctrl+P (Windows) or Cmd+P (Mac) to open the switcher
  • Start typing a note title — results filter as you type
  • Use ↑ ↓ to navigate, Enter to open, Esc to close
  • Also accessible via the 🔍 button in the notes list header

5. 🔙 Backlinks New

See which other notes reference the currently open note:

  • When you open a note, a "Backlinks (N)" panel appears below the editor
  • Backlinks are detected automatically from [[Title]] references in other notes
  • Click any backlink entry to navigate to that note
  • No backlinks = no panel shown

6. 🏷️ Tagging New

Adding tags to a note

  1. Below the note title, find the Add tag... input
  2. Type a tag name and press Enter — if the tag exists, it's added; otherwise it's created
  3. Tags appear as colored badges next to the input
  4. Click the ✕ on a tag badge to remove it

Filtering by tag

  1. In the sidebar, a TAGS section lists every tag with its note count
  2. Click a tag to show only notes with that tag
  3. Click a notebook to clear the tag filter

7. 📌 Pin / Favorite New

Keep important notes at the top of the list:

  • Hover over a note in the list and click the 📍 icon — it turns into 📌
  • Pinned notes always appear first (ordered by most recently updated)
  • Click 📌 again to unpin

8. 📥 Markdown Export New

Export any note as a .md file:

  1. Open the note you want to export
  2. Click the 📥 button in the note header (next to the Trash button)
  3. Choose a save location in the system dialog
  4. The file is saved with the note title as filename + # Title frontmatter

Formatting (bold, headings, lists, etc.) is preserved as proper Markdown.

9. 📊 Word Count New

The status bar at the bottom of the editor shows live statistics:

  • Words — total word count
  • Characters — total character count
  • Reading time — estimated minutes (at 200 words/minute)

Updates in real time as you type.

General Tips

  • Auto-save — notes save automatically 1 second after you stop typing
  • Search — use the top bar to search across all notes (title + content)
  • Trash — deleted notes go to trash; restore them later or permanently delete
  • Notebooks — organize notes into notebooks for clean separation
